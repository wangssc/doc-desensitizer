纯本地运行 · 不联网 · 不上传 · 关掉窗口即退出
脱敏
还原

1选择资料

把客户资料拖到这里，或点击选择
支持 .docx / .txt / .md / .csv，可一次选多个

2敏感词表（可选，一行一个）

自动识别覆盖不到的词放这里。填了它，脱得最干净——尤其是裸地名和没有上下文的人名。

3开始

映射表里是原文对照，明文落到磁盘上等于没脱敏。 必须设口令（至少 6 位），没填不能开始；口令丢了就还原不回来。

1脱敏后的文件

把脱敏文件拖到这里，或点击选择
还原后会生成「原名_还原」文件

2映射表 json

选择脱敏时生成的映射表
文件名形如 映射表_1107_1030.json
映射表是加密的，没有口令解不开；口令就是脱敏时设的那个。
还原后的文件等于原始资料，注意存放在哪台机器、哪个目录。
⚠

映射表里存的是原文，拿到它就能把脱敏件还原回去

它和脱敏件一起发出去，等于没脱敏。映射表强制用口令加密（不可关闭），但口令别跟着文件走—— 对外只发带「_脱敏」的文件；映射表只在需要还原时用，用完单独存放或删掉，别跟脱敏件放在同一个文件夹里。
