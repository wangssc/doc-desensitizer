# 文档脱敏工具

把方案 / 资料里的可识别信息替换成统一占位符，让文件可以安全外发，
同时保留撰写方案需要的全部技术颗粒度——数据量、架构、算法、指标都不动。

纯本地运行。不联网、不上传、不需要账号。

---

## 它做什么

读一份 `.docx` / `.txt` / `.md` / `.csv`，把里面的可识别信息换成 `[类型+序号]`：

| 类型 | 例子（脱敏前 → 脱敏后） |
|---|---|
| 人名 | 张伟 → `[人员1]` |
| 单位名 | 某某市财政局 → `[单位1]` |
| 地名 | 某某区 → `[地名1]` |
| IP / 网段 | 10.1.2.3 → `[IP1]` |
| 电话 / 邮箱 | → `[电话1]` / `[邮箱1]` |
| 账号 / 证件号 | → `[账号1]` / `[证件号1]` |
| 域名 / 路径 | www.example.com → `[域名1]` |
| 设备型号 / 编号 | → `[型号1]` / `[编号1]` |

同一个原文始终映射到同一个占位符，所以上下文读得通，逻辑链不会断。

输出三样东西：

- `<原名>_脱敏.docx` —— 可以外发的版本
- `映射表_<时间>.json` —— **含原文，能还原，严禁外发**。默认用口令加密（PBKDF2 +
  HMAC-SHA256，纯标准库），没有口令打不开，误发出去也不至于全盘皆输
- `脱敏报告_<时间>.md` —— 替换了什么、哪里可能还有残留，**不含原文**

需要还原时，拿脱敏件 + 映射表 + 脱敏时设的口令，一条命令换回原文（只在本地用）。

两种模式：

- **普通**（默认）：只替换有把握的
- **激进**（`--aggressive`）：连疑似人名也替换，误杀率上升，仔细校对

## 它不做什么

这一段比上面重要。

- **不支持 PDF。** 只吃 `.docx` / `.txt` / `.md` / `.csv`。PDF 请先用 Word 另存为 docx。
- **扫描件不行。** 没有文字层的东西谁也读不出字来，本工具不做 OCR。
- **Word 里的图片读不到。** 图里的 IP、系统名、拓扑标注、印章，全都脱不到。
  docx 可以选「删图」（`--images strip`，最稳）或「保留」——保留时报告会列清单，
  提醒你自己去看图里有什么。**图里的东西只能靠人眼。**
- **以「平台」结尾的名称不会被自动替换。** 单位名是靠后缀表认的（公司 / 集团 / 医院 /
  大学 / 银行 / 研究院 …），这张表里没有「平台」。为了不误伤「云平台」「数据平台」
  这类通用词，本工具不猜——但「××市××云平台」这种带行政区划的串会被列进报告的
  「残留风险」，看得见就不会漏；把整串加进词表重跑一次即可。
- **不做语义判断。** 它只做规则匹配。「某部门」「该单位」这种本来就没写具体名的，
  不会被处理；反过来，长得像人名的术语也可能被误伤（激进模式下更明显）。
- **不判断脱敏后能不能发。** 它把能认出来的换掉，剩下靠你看报告里的残留提示。

## 数据去哪了

- **只监听 `127.0.0.1:8765`**。回环地址，局域网里别的机器连不进来。
- **不上传、不需要账号、不统计。** 没有登录、没有遥测、没有「匿名使用数据」。
- **唯一的对外动作是启动时打开浏览器**（`webbrowser.open` 调本机默认浏览器）。
  界面不加载任何外部资源——没有 CDN、网络字体、图标库。
  想自己核：F12 打开 Network，所有请求的 Host 都应该是 `127.0.0.1:8765`。
- 所有输出都在本机 `out/desens/<批次>/` 下，想删随时删。

判断一个东西要不要发出去之前，先看它是不是 `映射表*.json`——
**映射表里有原文，它和脱敏件一起发出去，等于没脱敏。**

## 怎么用

**最简单**：双击 `启动脱敏工具.bat`（需要装 Python 3.8+），浏览器会自动打开。
把文件拖进虚线框就行。

**或者**：

```bash
python desensitize_server.py
```

**命令行**（适合批处理）：

```bash
python desensitize.py 客户端资料.docx
python desensitize.py 客户端资料/ -o out/desens
python desensitize.py 资料.docx --dict 敏感词表.txt      # 补充自己的词表，最可靠
python desensitize.py 资料.docx --aggressive             # 激进模式
python desensitize.py 资料.docx --images strip           # docx 里的图直接删掉
python desensitize.py 资料.docx --map-password 口令       # 映射表加密（推荐）
python desensitize.py 脱敏版.docx --restore out/desens/映射表_xxx.json --map-password 口令
```

退出码：`0` 正常；`2` 有高风险残留，需要人工复核。

### 用自定义词表

自动识别总有漏的，尤其是行业内部叫法。最可靠的办法是把这些词写成文本文件，
一行一个，`#` 开头是注释，然后 `--dict` 传进去。界面上也有对应入口。

## 打包成 exe

不想给同事装 Python，就打一个单文件 exe：

```bash
pip install pyinstaller python-docx
pyinstaller DesensTool.spec --noconfirm
```

产物在 `dist/DesensTool.exe`，双击即用。

`console=False` 所以不弹黑框；`datas` 把 `ui/index.html` 打进包里，
所以 exe 是自包含的，拷到别的机器上也能跑。

## 回归基线

改完之后跑一下这个，数字对不上就是改坏了：

```
sample.txt 普通模式  → 替换 24 处
sample.txt 激进模式  → 替换 26 处
```

另外 `python -c "import desensitize"` 要能导入（没装 python-docx 也能导入，
只有处理 docx 时才需要它）。

## 依赖

- Python 3.8+
- `python-docx`（只有处理 `.docx` 需要；`.txt` / `.md` / `.csv` 不用）

其余全是标准库。
