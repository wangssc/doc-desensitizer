# 文档脱敏工具

把方案 / 资料里的可识别信息替换成统一占位符，让文件可以安全外发，
同时保留撰写方案需要的全部技术颗粒度——数据量、架构、算法、指标都不动。

纯本地运行。不联网、不上传、不需要账号。

---

## 它做什么

读一份 `.docx` / `.txt` / `.md` / `.csv`，把里面的可识别信息换成 `[类型+序号]`。
一共识别 **17 类**：

| # | 类型 | 占位符 | 例子（脱敏前 → 脱敏后） |
|---|---|---|---|
| 1 | 人名 | `[人员N]` | 张伟 → `[人员1]` |
| 2 | 单位名 | `[单位N]` | 某某市财政局 → `[单位1]` |
| 3 | 系统 / 平台名 | `[系统N]` | 山东省政务云（浪潮节点） → `[系统1]` |
| 4 | 厂商 | `[厂商N]` | 深信服 → `[厂商1]` |
| 5 | 产品 | `[产品N]` | 达梦 → `[产品1]` |
| 6 | 地址 | `[地址N]` | 北京市朝阳区建国路88号 100022 → `[地址1]` |
| 7 | 邮编 | `[邮编N]` | 邮政编码：250014 → `[邮编1]` |
| 8 | IP / 网段 | `[IPN]` | 10.1.2.3 → `[IP1]` |
| 9 | 电话 | `[电话N]` | 13805311234 → `[电话1]` |
| 10 | 邮箱 | `[邮箱N]` | → `[邮箱1]` |
| 11 | 账号 | `[账号N]` | → `[账号1]` |
| 12 | 证件号 | `[证件号N]` | → `[证件号1]` |
| 13 | 域名 / URL | `[域名N]` | www.example.com → `[域名1]` |
| 14 | 路径 | `[路径N]` | → `[路径1]` |
| 15 | 设备型号 | `[型号N]` | → `[型号1]` |
| 16 | 编号 | `[编号N]` | → `[编号1]` |
| 17 | 未分类 | `[未分类N]` | 方案名等识别不出类别的实体，报告里单列一节 |

同一个原文始终映射到同一个占位符，所以上下文读得通，逻辑链不会断。

不再有 `[自定义N]` 兜底：识别不出类别的落到 `[未分类N]`，并在报告里单独列一节
「无法分类的实体」，由人工确认。报告编号、控制编号这类文档自身标识不替换。

厂商和产品单独分类，不混进「单位」：**深信服是 `[厂商1]`，不是 `[单位1]`**。
「深信服科技股份有限公司」这种整串单位名里含厂商的，整串按厂商记。

### 地址：整段替换，不换一半

地名（省 / 市 / 区 / 县 / 街道 / 建筑名）和紧邻的邮编合并成**一个** `[地址N]`：
`北京市朝阳区建国路88号 100022` → `[地址1]`，不会变成 `北京市[地址1]区` 这种半截结果。

识别偏保守：只有连续两级以上的行政区划、路名+门牌、或「大厦/广场/大楼」才认。
只写「朝阳区」这种半截地址不换，会出现在报告的「疑似地名残留」里，用 `--dict` 补。

### 日期：只换能定位到人的，技术时间点一律保留

满足条件的日期换成 `[日期N]`，映射表里留底（能还原）：

- 格式：`YYYY年M月D日` / `YYYY.M.D` / `YYYY-MM-DD`
- **换**：日期所在分句里出现「签订 / 签署 / 出生 / 入职 / 毕业 / 身份证有效期」这类定位词
- **不换**：报告日期、方案评估起止、证书有效期、人员考试/资格时间——这些是技术事实，
  换成占位符读者就没法判断方案对不对

```
2024年6月1日签订合同            → [日期1]签订合同
证书有效期至2027年6月1日        → 原样保留
系统于2024年6月1日上线          → 原样保留
```

### 保护白名单：命中就不换

这些词高频出现，形状上又容易撞进人名规则（「解」「符」「通」「关」「全」都是姓），
命中白名单就不替换：

- 结论词：通过 / 未通过 / 符合 / 基本符合 / 不符合 / 部分符合 / 不适用
- 表头词：标准要求 / 指标说明 / 测评方法 / 预期结果 / 适用对象
- 数量与程度词：1 / 2 / 3 / 重要 / 一般 / 关键 / 主要 / 次要
- 常见技术词：解密 / 加密 / 部署 / 集成 / 站点证书 / 如下 / 全局 / 采用 / 分设 / 配置 / 运行 / 维护

**只对独立成词生效**：该词前后必须是行首 / 行尾 / 空格 / 标点，不做词内匹配。
所以「重要客户张三」里的「张三」照换，「重要客户」不会被整串放过。

### 可读性回检：三条机械检查

不判断「通顺」（那需要语言模型）。脱敏后按字符位置做三条检查，命中就进
报告第七节和界面上的「疑似误伤」红字清单，**不阻断**：

1. 占位符被拆在词中间：左右紧贴汉字，如 `深[单位1]服`、`[厂商1]的服务器`
2. 占位符紧贴中文标点：`，[单位1]`、`。[人员1]`
3. 连续两个以上占位符无间隔：`[单位1][人员1]`

清单里只显示占位符和紧邻的 1 个字符，不带原文。


输出三样东西：

- `<原名>_脱敏.docx` —— 可以外发的版本
- `映射表_<时间>.json` —— **含原文，能还原，严禁外发**。强制用口令加密（PBKDF2 +
  HMAC-SHA256，纯标准库），没有口令打不开，误发出去也不至于全盘皆输
- `脱敏报告_<时间>.md` —— 替换了什么、哪里可能还有残留，**不含原文**

Word 文件还会顺带清掉 Word 里看不见、发出去对方却看得见的东西：作者、最后修改人、
公司、标题/主题/备注、自定义属性、批注和批注作者、修订记录（接受修订）、隐藏文字
（去掉隐藏标记、文字保留并照常脱敏），并关掉修订跟踪。细节记在报告第五节。

需要还原时，拿脱敏件 + 映射表 + 脱敏时设的口令，一条命令换回原文（只在本地用）。

两种模式：

- **普通**（默认）：只替换有把握的
- **激进**（`--aggressive`）：连疑似人名也替换，误杀率上升，仔细校对

## 它不做什么

这一段比上面重要。

- **不支持 PDF。** 只吃 `.docx` / `.txt` / `.md` / `.csv`。PDF 请先用 Word 另存为 docx。
- **扫描件不行。** 没有文字层的东西谁也读不出字来，本工具不做 OCR。
- **Word 里的图片读不到。** 图里的 IP、系统名、拓扑标注、印章，全都脱不到。
  docx 可以选「删图」（`--images strip`，最稳）或「保留」——保留时报告会列清单，
  提醒你自己去看图里有什么。**图里的东西只能靠人眼。**
- **只认带行政区划的云平台名。** 「××省/市××政务云（××节点）」会被整体识别成 `[系统N]`；
  光秃秃的「云平台」「数据平台」是通用词，不猜。整篇反复出现的系统全名（≥3 次）
  会先做整段匹配，再逐段替换，避免「前半截占位符 + 后半截原文」。
- **不做语义判断。** 它只做规则匹配。「某部门」「该单位」这种本来就没写具体名的，
  不会被处理；反过来，长得像人名的术语也可能被误伤（激进模式下更明显）。
- **不判断脱敏后能不能发。** 它把能认出来的换掉，剩下靠你看报告里的残留提示。

## 数据去哪了

- **只监听 `127.0.0.1:8765`**。回环地址，局域网里别的机器连不进来。
- **不上传、不需要账号、不统计。** 没有登录、没有遥测、没有「匿名使用数据」。
- **唯一的对外动作是启动时打开浏览器**（`webbrowser.open` 调本机默认浏览器）。
  界面不加载任何外部资源——没有 CDN、网络字体、图标库。
  想自己核：F12 打开 Network，所有请求的 Host 都应该是 `127.0.0.1:8765`。
- 所有输出都在本机 `out/desens/<批次>/` 下，想删随时删。

判断一个东西要不要发出去之前，先看它是不是 `映射表*.json`——
**映射表里有原文，它和脱敏件一起发出去，等于没脱敏。**

## 怎么用

三条路，按「多久用一次」选。

### 一、剪贴板守护（最常用：把一段话贴给 AI 之前）

双击 `DesensClip.exe`（或 `python clip/clipwatch.py`），缩到托盘。
之后你**复制**一段含单位名/人名/电话的文字，右下角弹一张卡片：

> 脱敏助手
> 命中 2 处 · 2 类：单位 1、电话 1
> 点「脱敏」把剪贴板换成脱敏版

点「脱敏」→ 剪贴板直接变干净，接着 Ctrl+V 粘给 AI。想还原就点「还原」。
它只处理纯文本，只在你复制之后看一眼剪贴板，不抢焦点、不留原文。

### 二、图形界面（整份文件）

**最简单**：双击 `DesensTool.exe`（或 `启动脱敏工具.bat`，需要 Python 3.8+）。
选文件 → 设定输出目录 → 设口令 → 开始。出三样：脱敏件、映射表、脱敏报告。

### 三、命令行（批量）

```bash
python desensitize.py 客户端资料.docx --map-password 口令   # 口令必填，至少 6 位
python desensitize.py 客户端资料/ -o out/desens --map-password 口令
python desensitize.py 资料.docx --dict 敏感词表.txt --map-password 口令   # 补充自己的词表，最可靠
python desensitize.py 资料.docx --aggressive --map-password 口令          # 激进模式
python desensitize.py 资料.docx --images strip --map-password 口令        # docx 里的图直接删掉
python desensitize.py 脱敏版.docx --restore out/desens/映射表_xxx.json --map-password 口令
```

映射表口令是**硬要求**：不传就不跑。映射表里是原文对照，明文落盘等于没脱敏。

退出码：`0` 正常；`2` 有高风险残留，需要人工复核。

### 用自定义词表

自动识别总有漏的，尤其是行业内部叫法。最靠谱的办法是把这些词写成文本文件
（仓库里的 `敏感名单.example.txt` 可以直接改名用），一行一个，`#` 开头是注释：

```
[单位]
某某市大数据中心
[项目]
星海数据中台
```

放在 `desensitize.py`（或 `DesensTool.exe`）同目录即自动加载，也可以用 `--dict` 显式指定。
**写进去的词一定被替换**，哪怕程序自己认不出来——这是兜底，也是最后一道闸。

## 打包成 exe

不想给同事装 Python，就打单文件 exe：

```bash
pip install pyinstaller python-docx

# 生成两个 exe
pyinstaller DesensTool.spec --noconfirm
cd clip && pyinstaller --noconfirm --onefile --windowed --name DesensClip \
  --paths .. --add-data "../app.ico;." clipwatch.py
```

产物：`dist/DesensTool.exe`（文件处理）、`clip/dist/DesensClip.exe`（剪贴板守护）。
打包版把状态与映射表放在 `%LOCALAPPDATA%\DesensClip\`，不写在 exe 旁边。
